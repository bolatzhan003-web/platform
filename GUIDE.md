## ➕ ДОБАВЛЕНИЕ КОНТЕНТА {#добавление-контента}

### Как создать новый курс:

#### Способ 1: Через админ-панель

1. Откройте http://127.0.0.1:8000/admin
2. Войдите как `admin` / `admin123`
3. Нажмите **"Courses"** → **"Add Course"**
4. Заполните:
   - **Title:** Название курса (например, "JavaScript Basics")
   - **Description:** Описание курса
   - **Author:** Выберите учителя
   - **Students:** Выберите учеников (можно выбрать несколько)
5. Нажмите **"Save"**

### Как добавить урок к курсу:

1. В админ-панели нажмите **"Lessons"** → **"Add Lesson"**
2. Заполните:
   - **Course:** Выберите курс
   - **Title:** Название урока (например, "1. Variables in JavaScript")
   - **Video URL:** Вставьте ссылку с YouTube
   - **Content:** Текст урока (описание, что изучим)
   - **Order:** Порядковый номер (1, 2, 3...)
3. Нажмите **"Save"**

### Откуда брать YouTube ссылки:

#### ✅ ВАЖНО: Используйте видео, которые разрешают встраивание!

**Проверенные каналы (всегда работают):**
- freeCodeCamp: https://www.youtube.com/@freecodecamp
- Programming with Mosh: https://www.youtube.com/@programmingwithmosh
- Traversy Media: https://www.youtube.com/@TraversyMedia
- Corey Schafer: https://www.youtube.com/@coreyms
- Net Ninja: https://www.youtube.com/@NetNinja

**Как скопировать ссылку:**
1. Откройте видео на YouTube
2. Скопируйте URL из адресной строки
3. Формат: `https://www.youtube.com/watch?v=VIDEO_ID`
4. Или: `https://youtu.be/VIDEO_ID`

### Как добавить ученика к курсу:

1. В админке откройте **"Courses"**
2. Найдите нужный курс
3. Нажмите на него
4. В разделе **"Students with access":**
   - Выберите учеников из списка слева
   - Нажмите стрелку → чтобы добавить
5. Нажмите **"Save"**

### Как создать нового пользователя:

1. Админка → **"Users"** → **"Add User"**
2. Заполните:
   - **Username:** логин (например, student4)
   - **Password:** пароль (например, student123)
   - Нажмите "Save and continue editing"
3. Дополнительно заполните:
   - **First name:** Имя
   - **Last name:** Фамилия
   - **Email:** email
   - **Role:** Выберите роль (student/teacher/admin)
4. Нажмите **"Save"**

### ШАГ 2: Разверните на Render.com

#### 2.1 Войдите на Render:

1. Откройте https://render.com
2. Нажмите **"Get Started"** или **"Sign Up"**
3. Войдите через GitHub

#### 2.2 Создайте Web Service:

**Способ A: Через Blueprint (рекомендуется)**

1. В Render нажмите **"New"** → **"Blueprint"**
2. Подключите GitHub репозиторий `lms-platform`
3. Render найдёт файл `render.yaml` и автоматически настроит всё
4. Нажмите **"Apply"**

**Способ B: Вручную**

1. Нажмите **"New"** → **"Web Service"**
2. Подключите GitHub → выберите `lms-platform`
3. Настройки:
   - **Name:** `lms-platform`
   - **Region:** выберите ближайший
   - **Branch:** `main`
   - **Runtime:** `Python 3`
   - **Build Command:**
     ```
     pip install -r requirements.txt && python manage.py collectstatic --noinput && python manage.py migrate
     ```
   - **Start Command:**
     ```
     gunicorn lms.wsgi:application --bind 0.0.0.0:$PORT --workers 2 --timeout 120
     ```

#### 2.3 Добавьте переменные окружения:

В Render → **Environment**:

| Key | Value |
|-----|-------|
| `DJANGO_SECRET_KEY` | Сгенерируйте новый (см. ниже) |
| `DJANGO_DEBUG` | `False` |
| `ALLOWED_HOSTS` | `.onrender.com,localhost` |
| `DATABASE_URL` | `postgresql://postgres:29101997.1064sh@db.tugldzcyfvmqogquzvif.supabase.co:5432/postgres?sslmode=require` |

**Генерация нового SECRET_KEY:**

В командной строке:
```bash
python -c "import secrets; print(secrets.token_urlsafe(50))"
```

Скопируйте результат и вставьте в `DJANGO_SECRET_KEY`

#### 2.4 Деплой:

1. Нажмите **"Create Web Service"**
2. Render начнёт деплой (займёт 3-5 минут)
3. Дождитесь "Live" статуса

#### 2.5 Создайте админа на продакшене:

1. В Render → ваш сервис → **Shell**
2. Выполните:
   ```bash
   python manage.py createsuperuser
   ```

3. Введите:
   - Username: `admin`

## ⚠️ РЕШЕНИЕ ПРОБЛЕМ {#проблемы}

### Ошибка: "Port 8000 is already in use"

**Решение:**
```bash
# Остановите старый сервер
# Найдите процесс
netstat -ano | findstr :8000

# Убейте процесс (замените PID)
taskkill /PID <номер_процесса> /F
```

### Ошибка YouTube 153

**Причина:** Владелец видео запретил встраивание

**Решение:**
1. Используйте видео с образовательных каналов (список выше)
2. Или нажмите "Открыть на YouTube" под видео

### База данных не подключается

**Проверьте:**
1. Файл `.env` существует
2. `DATABASE_URL` правильный
3. Интернет подключен (для Supabase)

**Решение:**
```bash
# Переключитесь на локальную БД
switch-env.bat local
```

### Статические файлы не загружаются

**Решение:**
```bash
python manage.py collectstatic --noinput
```

### "No module named 'django'"

**Решение:**
```bash
# Активируйте виртуальное окружение
venv\Scripts\activate

# Установите зависимости
pip install -r requirements.txt
```
